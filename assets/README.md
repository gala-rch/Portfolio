# Comment ajouter tes fichiers

Tu peux déposer tes fichiers ici toi-même, directement sur GitHub, sans passer par le chat :

1. Va sur https://github.com/gala-rch/Portfolio
2. En haut à gauche, clique sur le sélecteur de branche (marqué "main") et choisis
   `claude/beautiful-ramanujan-ye2v1f`
3. Ouvre le dossier `assets/` puis le sous-dossier du projet concerné
4. Clique sur **Add file → Upload files**, glisse tes fichiers, puis clique sur
   **Commit changes** (en bas, directement sur cette branche — pas besoin de faire
   une pull request)
5. Reviens dans le chat et dis-moi simplement "j'ai ajouté les fichiers dans
   assets/xxx" — je les récupère et je les intègre dans la page

Limite : l'upload web de GitHub accepte des fichiers jusqu'à 25 Mo chacun. Si un
export dépasse cette taille (typiquement une vidéo assez longue ou en très
haute résolution), dis-le moi, on trouvera une solution (compression, ou découpe).
